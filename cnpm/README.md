# Personal Wealth & Expense Tracker (frontend)

Ứng dụng Next.js (App Router) cho phần giao diện quản lý thu chi. Xem thêm mô tả dự án ở README gốc của repo.

## Chạy dự án

```bash
npm install
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev`: chạy môi trường phát triển
- `npm run build`: build production
- `npm run start`: chạy bản build
- `npm run lint`: kiểm tra ESLint
